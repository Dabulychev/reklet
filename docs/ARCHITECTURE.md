# Reklet — Архитектура

## Текущая архитектура

Сейчас приложение Reklet находится преимущественно в одном файле:

`app.py`

Файл содержит:

- интерфейс Streamlit;
- подключение к PostgreSQL;
- SQL-запросы;
- бизнес-логику;
- создание и миграцию таблиц;
- работу с клиентами;
- объекты;
- изделия;
- материалы;
- производство;
- закупки;
- поставщиков;
- готовую продукцию;
- транспорт;
- монтаж;
- зарплату;
- отчёты.

## Результат аудита app.py

Текущий `app.py` — большой монолитный файл.

Внутри него уже существуют отдельные функциональные области, которые в дальнейшем могут быть выделены в самостоятельные модули.
